# React Testing Lab

A small React banking app — The Royal Bank of Flatiron — that lets users view, add, search, and sort transactions. Backed by a `json-server` mock API, with a Vitest + React Testing Library suite covering display, add, search, and sort behavior.

## Running the app

Install dependencies:
```sh
npm install
```

Run the backend API (json-server on port 6001):
```sh
npm run server
```

Run the frontend (in a separate terminal):
```sh
npm run dev
```

## Running the tests

```sh
npm test
```
